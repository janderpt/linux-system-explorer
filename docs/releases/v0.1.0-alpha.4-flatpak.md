# Linux System Explorer alpha.4 — Flatpak experimental

Bundle **x86_64**, branch **experimental**, aplicativo `io.github.janderpt.linux-system-explorer`. É um pacote de testes publicado no GitHub; não é uma publicação no Flathub e ainda não oferece todos os recursos dos pacotes nativos.

Downloads: https://github.com/janderpt/linux-system-explorer/releases/tag/v0.1.0-alpha.4

## Requisitos

- Linux x86_64 com uma instalação Flatpak atualizada, mantida pela distribuição.
- `xdg-dbus-proxy` **0.1.9 ou posterior**. O proxy 0.1.5 do Ubuntu 24.04 original não atende às chamadas D-Bus deste aplicativo; o runtime não atualiza esse componente do host.
- Sessão gráfica com Wayland ou X11. O runtime **Freedesktop Platform 26.08** é instalado separadamente; a primeira instalação precisa de rede para baixá-lo.

## Verificar os arquivos

Baixe o bundle, `FLATPAK-BUILD-INFO.json`, `FLATPAK-VALIDATION.json`, `INSTALL-FLATPAK.md` e `FLATPAK-SHA256SUMS` da mesma release. Na pasta dos downloads:

```sh
sha256sum --check FLATPAK-SHA256SUMS
```

Se baixou apenas o bundle e os checksums:

```sh
grep '  linux-system-explorer-0.1.0-alpha.4-flatpak-experimental-x86_64.flatpak$' FLATPAK-SHA256SUMS | sha256sum --check -
```

O arquivo `SHA256SUMS` sem prefixo continua sendo o manifesto dos pacotes nativos `.deb`/`.tar.gz`. Os anexos Flatpak usam `FLATPAK-SHA256SUMS` para evitar colisões.

## Instalar

Com Flatpak e o proxy compatível instalados pela distribuição, execute na pasta do bundle:

```sh
flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user ./linux-system-explorer-0.1.0-alpha.4-flatpak-experimental-x86_64.flatpak
flatpak run --branch=experimental io.github.janderpt.linux-system-explorer
```

O Flathub fornece o runtime; o aplicativo vem do arquivo local recebido nesta release. O bundle não inclui o runtime e não tem assinatura GPG nem atualização automática por repositório próprio.

## Atualizar uma instalação anterior

O protótipo anterior disponível era a **alpha.2**; a alpha.3 foi publicada nos formatos nativos. Feche as janelas Flatpak e instale o novo bundle **sem desinstalar nem apagar dados**:

```sh
flatpak install --user ./linux-system-explorer-0.1.0-alpha.4-flatpak-experimental-x86_64.flatpak
flatpak info --user io.github.janderpt.linux-system-explorer//experimental
flatpak run --branch=experimental io.github.janderpt.linux-system-explorer
```

A origem, o ID e a branch são preservados. As preferências continuam em `~/.var/app/io.github.janderpt.linux-system-explorer/`, separadas das preferências da instalação nativa. Não use `--delete-data` ao atualizar. Este pacote não altera o gerenciador de arquivos padrão nem registra FileManager1 no host.

Para remover somente o aplicativo, mantendo os dados:

```sh
flatpak uninstall --user io.github.janderpt.linux-system-explorer//experimental
```

## Recursos, limitações e testes

Pastas, abas, dois painéis, teclado, filtro recursivo, operações de arquivos, imagens, texto, GStreamer, compactados e terminal do sandbox usam o código alpha.4. Acesso a arquivos usa a permissão `filesystem=host`; não há execução irrestrita no host, rede própria ou acesso irrestrito aos barramentos D-Bus.

**Poppler, LibreOffice e WeasyPrint ainda não estão incluídos:** previews de PDF/Office e apresentação HTML/Markdown não estão disponíveis neste bundle. Imprimir PDF individual usa o portal; preparação de outros tipos e seleção múltipla dependem dos conversores ausentes. Aplicativos do menu do host, montagem de novas conexões remotas, gerenciamento Samba local, unidades UDisks2 e integração FileManager1 continuam pendentes. Pastas remotas já montadas dependem dos caminhos expostos. A Lixeira usa dados XDG do sandbox. Instalar conversores apenas no host não os disponibiliza automaticamente no Flatpak.

O bundle foi testado com Flatpak **1.14.6**, proxy **0.1.9** e Freedesktop **26.08**, em container descartável com D-Bus próprio e Xvfb/software OpenGL. Passaram instalação nova, atualização alpha.2 → alpha.4 no mesmo ref/origem, preservação exata das preferências, abertura gráfica e remoção. Também passaram **33 testes funcionais dentro do sandbox**, incluindo transferências, terminal, toasts, teclado/filtro/painéis, miniaturas, compactados e Lixeira. O relatório `FLATPAK-VALIDATION.json` registra os resultados e o commit OSTree; `FLATPAK-BUILD-INFO.json` identifica a revisão fonte, binário, runtime e permissões. A sessão real KDE/GNOME e Wayland não foi certificada.

Fonte do bundle e das instruções de teste: https://github.com/janderpt/linux-system-explorer/tree/40b3afd87079f4dc1dd4a7439efb7c68862e13c4

Licenças, avisos de terceiros e fontes MPL acompanham o bundle. Relate problemas em https://github.com/janderpt/linux-system-explorer/issues, informando versão, distribuição, desktop e sessão gráfica, sem senhas ou dados privados.

## English summary

This **x86_64 experimental Flatpak** is a GitHub test bundle, not a Flathub release. It requires maintained Flatpak, host xdg-dbus-proxy **0.1.9+** and Freedesktop Platform **26.08**. Add the Flathub runtime remote, then install the local `.flatpak` with `flatpak install --user FILE.flatpak` and run `flatpak run --branch=experimental io.github.janderpt.linux-system-explorer`. Verify the Flatpak assets using **FLATPAK-SHA256SUMS**; the existing SHA256SUMS remains native-only.

To upgrade the previous alpha.2 prototype, close its windows and install the alpha.4 bundle on the same experimental branch **without uninstalling or deleting data**. Origin/ref and private preferences are preserved. Neither installation nor removal changes host MIME defaults/FileManager1. The unsigned bundle has no automatic repository updates.

Fresh install, same-ref upgrade, preferences, Xvfb startup/removal and **33 sandbox functional tests** passed in an isolated container. Native desktop/Wayland certification remains pending. PDF/Office/formatted HTML/Markdown converters and several host integrations are not yet included; use the native packages when those features are required. Consult the attached build/validation reports for exact provenance, capabilities and permissions.
