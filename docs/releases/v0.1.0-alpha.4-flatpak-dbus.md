# Linux System Explorer alpha.4 — Flatpak com previews e compatibilidade D-Bus

Variante experimental **x86_64** com Poppler, LibreOffice e WeasyPrint incluídos. Previews de **PDF, Office/OpenDocument e apresentação de HTML/Markdown**, miniaturas e preparação de impressão usam componentes do próprio Flatpak. Não é necessário instalar esses conversores no host.

Downloads: https://github.com/janderpt/linux-system-explorer/releases/tag/v0.1.0-alpha.4

Escolha **linux-system-explorer-0.1.0-alpha.4-flatpak-previews-dbus-x86_64.flatpak**. As variantes anteriores `flatpak-experimental` (sem conversores) e `flatpak-previews` (com conversores, antes da correção D-Bus) continuam disponíveis como histórico, com seus requisitos e checksums originais. Os pacotes nativos e a tag alpha.4 permanecem inalterados.

Esta atualização corrige a comunicação D-Bus e mantém os conversores incluídos. Os nomes com **DBUS** distinguem o novo build e os seus relatórios. O anexo de fontes dos conversores **FLATPAK-PREVIEW-SOURCES.tar** é reutilizado, sem alteração, e também consta nos novos checksums.

## Requisitos

- Linux x86_64, sessão gráfica Wayland ou X11 e Flatpak mantido pela distribuição.
- Proxy D-Bus fornecido e mantido pela distribuição. Esta variante usa **zbus 5.19 com autenticação sequencial**, testada com `xdg-dbus-proxy` **0.1.5 e 0.1.9**, sem exigir substituição ou atualização manual do proxy. Mantenha as atualizações normais do sistema.
- Freedesktop Platform **26.08**, baixada pelo Flatpak na primeira instalação. Essa instalação precisa de rede; os conversores incluídos não precisam de outra instalação do LibreOffice, Poppler ou WeasyPrint.

## Verificar os downloads

Baixe o bundle e `FLATPAK-DBUS-SHA256SUMS`. Para verificar somente o bundle:

```sh
grep '  linux-system-explorer-0.1.0-alpha.4-flatpak-previews-dbus-x86_64.flatpak$' FLATPAK-DBUS-SHA256SUMS | sha256sum --check -
```

Se baixou todos os anexos dessa variante, incluindo relatórios, instruções e fontes:

```sh
sha256sum --check FLATPAK-DBUS-SHA256SUMS
```

`SHA256SUMS` continua exclusivo dos pacotes nativos, e `FLATPAK-SHA256SUMS` continua identificando o Flatpak anterior. Use **FLATPAK-DBUS-SHA256SUMS** para este pacote. **FLATPAK-PREVIEW-SHA256SUMS** identifica a variante anterior com conversores, que permanece inalterada.

## Instalar

Na pasta do arquivo baixado:

```sh
flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user ./linux-system-explorer-0.1.0-alpha.4-flatpak-previews-dbus-x86_64.flatpak
flatpak run --branch=experimental io.github.janderpt.linux-system-explorer
```

O aplicativo vem deste arquivo local; o Flathub fornece o runtime. Esta é uma pré-release experimental, sem publicação na loja, assinatura GPG ou atualização automática por repositório próprio.

## Atualizar uma alpha.4 anterior ou a alpha.2 experimental

Feche as janelas Flatpak e execute o mesmo comando de instalação acima **sem desinstalar nem apagar os dados**. O ID e a branch `experimental` permanecem iguais. O novo pacote tem o mesmo número alpha.4, mas um commit OSTree diferente; instalar o arquivo atualiza a instalação anterior.

```sh
flatpak install --user ./linux-system-explorer-0.1.0-alpha.4-flatpak-previews-dbus-x86_64.flatpak
flatpak info --user io.github.janderpt.linux-system-explorer//experimental
flatpak run --branch=experimental io.github.janderpt.linux-system-explorer
```

A origem e as preferências em `~/.var/app/io.github.janderpt.linux-system-explorer/` são preservadas. Não use `--delete-data`. A instalação nativa, seus padrões MIME e o explorador padrão do sistema não são alterados. O teste desta variante cobre diretamente a atualização **alpha.4 com previews anterior → alpha.4 com previews e correção D-Bus**; o fluxo alpha.2 → alpha.4 foi validado no pacote anterior.

Para remover o aplicativo, mantendo os dados:

```sh
flatpak uninstall --user io.github.janderpt.linux-system-explorer//experimental
```

## Conversores, fontes e origem

- Poppler **26.11.0** e dados Poppler **0.4.12**: PDF, páginas, miniaturas e `pdfunite` para preparação de impressão.
- LibreOffice **26.8.3.1**: Writer, Calc, Impress, Draw e Math; DOC/DOCX/ODT, XLS/XLSX/ODS, PPT/PPTX/ODP, desenhos, fórmulas e demais formatos já aceitos pelo explorador.
- WeasyPrint **70.0** com suas dependências Python: HTML/CSS estático, Markdown e preparação de imagens/texto para impressão. O renderizador mantém compatibilidade com a API anterior usada pela instalação nativa.
- MIT Kerberos **1.22.2**: biblioteca exigida pelo motor LibreOffice, sem ferramentas administrativas no pacote.

Os limites, cancelamento, cópias temporárias, perfil Office separado e bloqueio de macros/conteúdo ativo continuam aplicados. HTML não executa JavaScript nem busca recursos remotos. A paginação pode variar conforme as fontes. Documentos inválidos, protegidos ou não suportados continuam usando os avisos e ícones de fallback.

`FLATPAK-DBUS-BUILD-INFO.json` registra o commit exato do explorador, hashes, SDK/runtime, versões e permissões; o código dessa revisão está no anexo **FLATPAK-DBUS-APP-SOURCE.tar.gz**. Os botões automáticos “Source code” da release continuam apontando para a tag original dos pacotes nativos, portanto use o anexo específico para reconstruir este Flatpak.

**FLATPAK-PREVIEW-SOURCES.tar** contém os fontes correspondentes dos conversores, seus insumos fixados, locks, licenças e procedimento de build. É um download separado e não precisa ser instalado para usar o aplicativo. Quem redistribuir este bundle deve disponibilizar também esse arquivo no mesmo local. As licenças e avisos de terceiros acompanham a instalação; os componentes não são relicenciados como MIT.

## Testes e limitações

Passaram instalação nova, atualização da alpha.4 com previews anterior na mesma origem/ref, preservação exata das preferências, abertura gráfica, reutilização de janelas e remoção em containers descartáveis com Flatpak 1.14.6, **proxies 0.1.5 e 0.1.9**, D-Bus próprio e Xvfb/software OpenGL. **43 testes funcionais no sandbox em cada versão do proxy** cobrem operações, teclado/painéis, PDF, famílias Office, HTML/Markdown, miniaturas e preparação de impressão, verificando conteúdo e preservação dos originais. Nenhum documento foi enviado a uma impressora. Consulte `FLATPAK-DBUS-VALIDATION.json` para o resultado do pacote exato.

Também passaram os testes de transporte com proxy real filtrado para OpenFile/Abrir com e Print: passagem de descritores, confirmação, cancelamento e erros, usando portais simulados em barramento privado. Os testes não chamam o portal da sessão do usuário nem enviam documentos a uma impressora. Os 362 testes Rust, 34 testes Python e Clippy completaram a validação do código.

A sessão real KDE/GNOME/Wayland e a impressão física permanecem sem certificação. Aplicativos do menu do host, novas conexões remotas, gerenciamento Samba local, unidades UDisks2 e FileManager1 continuam pendentes no Flatpak; pastas remotas já montadas dependem dos caminhos expostos. O terminal executa no sandbox, e a Lixeira usa dados XDG próprios. As permissões continuam sem rede própria, execução no host ou acesso irrestrito ao D-Bus.

`FLATPAK-DBUS-RUSTSEC-AUDIT.json` registra a auditoria das dependências Rust, sem vulnerabilidades conhecidas, mas com avisos informativos de manutenção para `ttf-parser` e para os componentes independentes `zbus_names`, `zvariant` e `zvariant_derive` da linha D-Bus anterior. Esses componentes foram incorporados pelo upstream ao zbus 6; esta alpha mantém a linha anterior pela compatibilidade testada com proxies da distribuição. A estratégia de manutenção precisa de revisão antes da versão estável/loja. O relatório não representa auditoria de segurança dos motores nativos incluídos. Relate problemas em https://github.com/janderpt/linux-system-explorer/issues, sem senhas ou documentos privados.

## English summary

Download **linux-system-explorer-0.1.0-alpha.4-flatpak-previews-dbus-x86_64.flatpak** and verify it with **FLATPAK-DBUS-SHA256SUMS**. This experimental x86_64 variant bundles Poppler, LibreOffice and WeasyPrint for PDF/Office/static HTML/Markdown previews, thumbnails and print preparation; host converter installations are unnecessary. It requires distribution-maintained Flatpak/D-Bus packages and Freedesktop Platform 26.08. Sequential authentication with zbus 5.19 supports distribution proxy 0.1.5; both 0.1.5 and 0.1.9 were tested, without manually replacing the host proxy. Install with `flatpak install --user FILE.flatpak` and run `flatpak run --branch=experimental io.github.janderpt.linux-system-explorer`.

Upgrade the old alpha.4/alpha.2 experimental branch by installing this bundle without uninstalling or deleting data. The version string remains alpha.4, while the OSTree commit changes; origin/ref and private preferences are preserved. Fresh install, direct upgrade from the earlier converter-equipped alpha.4, Xvfb startup/removal, window reuse and **43 sandbox functional tests per proxy version** passed. Separate filtered-proxy mock-portal tests verify file-descriptor transport and opening/printing cancellation/errors. Real desktop/Wayland and physical-print validation remain separate. Existing host-integration limitations still apply.

The original native assets, tag and both earlier Flatpak variants remain available unchanged. Use **FLATPAK-DBUS-APP-SOURCE.tar.gz** for the exact new explorer source and **FLATPAK-PREVIEW-SOURCES.tar** for the corresponding converter sources/build inputs. Redistributors must provide the converter source archive alongside this bundle. These source downloads are not needed to run the app. The prefixed build/validation/audit reports identify exact provenance, actual capabilities and test scope. RustSec reports no known vulnerable locked crates, but records informational unmaintained notices for ttf-parser and the standalone zbus_names/zvariant/zvariant_derive crates retained for proxy compatibility. The long-term dependency strategy needs review before stable/store publication. This is not a Flathub submission or a stable/store-certified release.
