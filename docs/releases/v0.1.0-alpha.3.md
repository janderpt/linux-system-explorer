# Linux System Explorer v0.1.0-alpha.3

Terceira pré-release para testes, Linux **x86_64/amd64**, compilada no **Ubuntu 24.04 (glibc 2.39)**. Não é uma versão estável nem um AppImage/Flatpak. Outras distribuições precisam de ABI e dependências compatíveis; sistemas com glibc anterior a 2.39 não são suportados por estes binários.

## Novidades desde a alpha.2

- **Busca recursiva:** o filtro procura nomes na pasta atual e nas subpastas em segundo plano, com resultados progressivos, cancelamento e caminhos relativos. Respeita itens ocultos e não percorre links simbólicos para diretórios. **Abrir local do arquivo**, no menu dos resultados, abre a pasta de origem com o item selecionado e visível.
- **Unidades:** seção configurável com volumes, capacidade e espaço livre; clique para montar/abrir e menu para desmontar ou ejetar com segurança pelo UDisks2/Polkit. Volumes essenciais são protegidos e não há desmontagem forçada.
- **Aparência por pasta:** cor e ícone Font Awesome em **Propriedades → Aparência**, persistentes independentemente do tema ou modo monocromático, com restauração individual do padrão.
- **Aplicativos:** lista plana dos lançadores do sistema nos modos Detalhes, Lista e Ícones, com busca e abertura; menu para Discover/GNOME Software conforme disponibilidade e ambiente.
- **Ações por tipo:** extrair compactados pelo gerenciador de arquivos compactados do desktop; girar, redimensionar e converter imagens gerando novas cópias e preservando os originais.
- **Impressão:** arquivos e seleções compatíveis usam o diálogo de impressão do sistema. No KDE, cada solicitação obtém uma nova configuração e confirmação antes do envio; cancelar não envia o documento.
- Preparação do Flatpak experimental e integrações com portais no código-fonte. O protótipo permanece separado desta publicação nativa e não é uma publicação no Flathub.

Continuam disponíveis as miniaturas da alpha.2, abas, dois painéis, preferências por pasta, terminal integrado, rede/Samba, Lixeira e previews com Espaço. As instruções detalhadas estão nos READMEs em português e inglês.

A busca tem limites de 20.000 resultados, um milhão de itens examinados e 128 níveis; falhas de acesso ou limites geram aviso de resultado parcial. Miniaturas e previews dependem dos componentes e codecs declarados no pacote. A extração requer Ark, File Roller ou Engrampa; a gestão de aplicativos depende do gerenciador de software e de seus módulos. Unidades precisam de `udisks2`, `polkitd` e do agente de autenticação do desktop, sem solicitar senhas dentro do explorador. A impressão requer `xdg-desktop-portal` e um backend com suporte a impressão; confirma o envio ao sistema, sem garantir a impressão física.

O nome público do DEB usa `.alpha.3`; a versão interna é `0.1.0~alpha.3-1`, para ordenar corretamente antes da versão final. Feche e reabra todas as janelas depois de atualizar.

## Downloads e integridade

Baixe o `.deb` ou `.tar.gz`, `BUILD-INFO.json` e `SHA256SUMS` desta release. Para verificar tudo, baixe todos os anexos listados em `SHA256SUMS` (os dois pacotes, metadados, relatórios e instruções) e execute na pasta dos downloads:

```sh
sha256sum --check SHA256SUMS
```

Se baixou apenas um pacote, verifique sua linha (e repita para BUILD-INFO.json, se desejado):

```sh
grep '  linux-system-explorer_0.1.0.alpha.3-1_amd64.deb$' SHA256SUMS | sha256sum --check -
# ou
grep '  linux-system-explorer-0.1.0-alpha.3-x86_64-unknown-linux-gnu.tar.gz$' SHA256SUMS | sha256sum --check -
```

## Instalar o DEB — Ubuntu 24.04+

```sh
sudo apt update
sudo apt install ./linux-system-explorer_0.1.0.alpha.3-1_amd64.deb
linux-system-explorer
```

O APT instala as dependências declaradas, incluindo os componentes de preview. Use a sessão gráfica do seu usuário, sem executar o explorador como root. A instalação do DEB não muda automaticamente o gerenciador de arquivos padrão. Para remover:

```sh
sudo apt remove linux-system-explorer
```

Para atualizar a alpha.1 ou alpha.2 instalada por DEB, use o mesmo comando de instalação acima; o APT reconhece a alpha.3 como mais recente. As preferências do usuário permanecem nos diretórios XDG. Ao atualizar/reinstalar, feche e reabra todas as janelas. Uma instalação anterior em `~/.local/bin` tem prioridade sobre `/usr/bin`; confira `command -v linux-system-explorer` e use `/usr/bin/linux-system-explorer` para testar este DEB.

## Executar o TAR.GZ

Este arquivo contém um executável nativo e os metadados/licenças; não inclui as bibliotecas do sistema. No Ubuntu 24.04+, instale os runtimes:

```sh
sudo apt install libx11-6 libxi6 libxcursor1 libxrandr2 libxkbcommon0 libxkbcommon-x11-0 libwayland-client0 libegl1 libgl1 libglib2.0-bin xdg-utils shared-mime-info hicolor-icon-theme poppler-utils libgstreamer1.0-0 libgstreamer-plugins-base1.0-0 gstreamer1.0-plugins-base gstreamer1.0-plugins-good gstreamer1.0-libav libreoffice-writer libreoffice-calc libreoffice-impress libreoffice-draw libreoffice-math fonts-liberation weasyprint python3 libarchive13t64 udisks2 polkitd xdg-desktop-portal

tar -xzf linux-system-explorer-0.1.0-alpha.3-x86_64-unknown-linux-gnu.tar.gz
./linux-system-explorer-0.1.0-alpha.3/bin/linux-system-explorer
```

Também é possível informar uma pasta após o executável. Os avisos de terceiros, fontes MPL e instruções ficam em `share/licenses` e `share/doc`.

## Tornar padrão / Mostrar na pasta

A integração é opcional. Siga o [instalador por usuário e sua restauração](https://github.com/janderpt/linux-system-explorer/tree/v0.1.0-alpha.3#instalar-pelo-código-do-github), usando o código da tag `v0.1.0-alpha.3`. Ele preserva os registros anteriores e configura `inode/directory` e FileManager1. Não habilite duas instalações diferentes para o mesmo usuário.

## Limitações e validação

- O workflow exige testes automáticos, auditoria, validação de origem/licenças e instalação/reinstalação/remoção em Ubuntu 24.04 limpo antes de publicar. A interface foi testada em KDE durante o desenvolvimento, incluindo a busca e a abertura da origem com seleção e rolagem confirmadas pelo usuário. Montagem/desmontagem/ejeção foram verificadas em um serviço simulado, com inventário real lido sem alterações. O diálogo de impressão foi conferido com cancelamento; a impressão física e a matriz completa GNOME/KDE e Wayland/X11 ainda não foram certificadas.
- Clipboard de arquivos entre outros gerenciadores e este app ainda não implementa os formatos MIME nativos; arrastar e soltar é uma integração separada.
- Unidades criptografadas precisam estar desbloqueadas; o desbloqueio não faz parte desta versão. Aplicativos, gerenciadores de software, extração e serviços de armazenamento dependem dos componentes fornecidos pelo desktop.
- Rede depende dos módulos GVfs/GTK ou KIO do desktop. O servidor Samba é opcional e não é instalado/configurado automaticamente.
- Office usa conversão estática pelo LibreOffice; HTML/Markdown usam apresentação estática, sem JavaScript. Arquivos protegidos/danificados, codecs ausentes ou limites de recursos podem impedir previews.
- RustSec reporta `ttf-parser` como não mantido (RUSTSEC-2026-0192); é uma dependência indireta do renderizador. O relatório de auditoria está anexado. As licenças, avisos e fontes MPL acompanham cada pacote; a revisão técnica está em `DISTRIBUTION-REVIEW.md`.

Relate problemas em https://github.com/janderpt/linux-system-explorer/issues, incluindo versão, distribuição, desktop, X11/Wayland e passos para reproduzir, sem senhas ou arquivos privados.

## English installation summary

Third **alpha**, **Ubuntu 24.04+ x86_64**, built against glibc 2.39. Verify downloads using SHA256SUMS. Install or upgrade with `sudo apt install ./linux-system-explorer_0.1.0.alpha.3-1_amd64.deb`; remove with `sudo apt remove linux-system-explorer`. Or install the listed native runtimes, extract the TAR.GZ and run `linux-system-explorer-0.1.0-alpha.3/bin/linux-system-explorer` in your graphical user session. Neither package changes the default file manager automatically. Close/reopen all windows after updating; check for an older `~/.local/bin` installation shadowing `/usr/bin`.

New since alpha.2: cancellable recursive name search and Open file location with selection/reveal; a configurable Drives sidebar with capacity/free space and UDisks2 mount/safe removal; per-folder icons/colors with individual reset; flat Applications views and software-manager integration; archive extraction actions; non-destructive image rotation/resize/conversion; type-aware printing with fresh system confirmation. Existing thumbnails, previews, tabs, split panes, per-folder preferences and network/file operations remain available. Extraction needs a supported archive manager; software management needs Discover/GNOME Software; storage requires UDisks2 and a Polkit desktop agent; printing requires a Print-capable desktop portal backend. Search limits yield explicit partial-result notices. The experimental Flatpak remains a separate prototype and is not included as a certified native-release asset or store submission.

The publication workflow checks tests/audit/notices and clean-container package installation/removal. KDE interface testing includes user-confirmed search-result location/selection/scrolling; volume actions were tested on a simulated service with read-only real inventory, and the native print dialog was tested by cancelling. Physical printing and the full desktop/session matrix remain unverified. The audit records the informational unmaintained `ttf-parser` dependency. Packages include third-party notices and unmodified MPL-covered crate sources. Report reproducible problems without private files or credentials.
