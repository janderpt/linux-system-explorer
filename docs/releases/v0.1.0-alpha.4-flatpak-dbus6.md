# Linux System Explorer alpha.4 — Flatpak com previews, zbus 6.2.1 e compatibilidade D-Bus

Variante experimental **x86_64** com Poppler, LibreOffice e WeasyPrint incluídos. Previews de **PDF, Office/OpenDocument e apresentação de HTML/Markdown**, miniaturas e preparação de impressão usam componentes do próprio Flatpak. Não é necessário instalar esses conversores no host.

Downloads: https://github.com/janderpt/linux-system-explorer/releases/tag/v0.1.0-alpha.4

Escolha **linux-system-explorer-0.1.0-alpha.4-flatpak-previews-dbus6-x86_64.flatpak**. As variantes anteriores `flatpak-experimental` (sem conversores), `flatpak-previews` (antes da correção D-Bus) e `flatpak-previews-dbus` (com zbus 5.19) continuam disponíveis como histórico, com seus requisitos e checksums originais. Os pacotes nativos e a tag alpha.4 permanecem inalterados.

Esta atualização usa **zbus 6.2.1** e remove os três avisos de manutenção D-Bus, preservando o proxy 0.1.5 e os conversores incluídos. Os nomes com **DBUS6** distinguem o novo build e os seus relatórios. O anexo de fontes dos conversores **FLATPAK-PREVIEW-SOURCES.tar** é reutilizado, sem alteração, e também consta nos novos checksums.

## Requisitos

- Linux x86_64, sessão gráfica Wayland ou X11 e Flatpak mantido pela distribuição.
- Proxy D-Bus fornecido e mantido pela distribuição. Esta variante usa **zbus 6.2.1 com um patch local de autenticação sequencial**, testada com `xdg-dbus-proxy` **0.1.5 e 0.1.9**, sem exigir substituição ou atualização manual do proxy. Mantenha as atualizações normais do sistema.
- Freedesktop Platform **26.08**, baixada pelo Flatpak na primeira instalação. Essa instalação precisa de rede; os conversores incluídos não precisam de outra instalação do LibreOffice, Poppler ou WeasyPrint.

## Verificar os downloads

Baixe o bundle e `FLATPAK-DBUS6-SHA256SUMS`. Para verificar somente o bundle:

```sh
grep '  linux-system-explorer-0.1.0-alpha.4-flatpak-previews-dbus6-x86_64.flatpak$' FLATPAK-DBUS6-SHA256SUMS | sha256sum --check -
```

Se baixou todos os anexos dessa variante, incluindo relatórios, instruções e fontes:

```sh
sha256sum --check FLATPAK-DBUS6-SHA256SUMS
```

`SHA256SUMS` continua exclusivo dos pacotes nativos, e `FLATPAK-SHA256SUMS` continua identificando o Flatpak anterior. Use **FLATPAK-DBUS6-SHA256SUMS** para este pacote. **FLATPAK-PREVIEW-SHA256SUMS** e **FLATPAK-DBUS-SHA256SUMS** identificam as variantes anteriores, que permanecem inalteradas.

## Instalar

Na pasta do arquivo baixado:

```sh
flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user ./linux-system-explorer-0.1.0-alpha.4-flatpak-previews-dbus6-x86_64.flatpak
flatpak run --branch=experimental io.github.janderpt.linux-system-explorer
```

O aplicativo vem deste arquivo local; o Flathub fornece o runtime. Esta é uma pré-release experimental, sem publicação na loja, assinatura GPG ou atualização automática por repositório próprio.

## Atualizar uma alpha.4 anterior ou a alpha.2 experimental

Feche as janelas Flatpak e execute o mesmo comando de instalação acima **sem desinstalar nem apagar os dados**. O ID e a branch `experimental` permanecem iguais. O novo pacote tem o mesmo número alpha.4, mas um commit OSTree diferente; instalar o arquivo atualiza a instalação anterior.

```sh
flatpak install --user ./linux-system-explorer-0.1.0-alpha.4-flatpak-previews-dbus6-x86_64.flatpak
flatpak info --user io.github.janderpt.linux-system-explorer//experimental
flatpak run --branch=experimental io.github.janderpt.linux-system-explorer
```

A origem e as preferências em `~/.var/app/io.github.janderpt.linux-system-explorer/` são preservadas. Não use `--delete-data`. A instalação nativa, seus padrões MIME e o explorador padrão do sistema não são alterados. O teste desta variante cobre diretamente a atualização **alpha.4 com zbus 5.19 → alpha.4 com zbus 6.2.1 e o patch de compatibilidade**; o fluxo alpha.2 → alpha.4 foi validado no pacote anterior.

Para remover o aplicativo, mantendo os dados:

```sh
flatpak uninstall --user io.github.janderpt.linux-system-explorer//experimental
```

## Conversores, fontes e origem

- Poppler **26.11.0** e dados Poppler **0.4.12**: PDF, páginas, miniaturas e `pdfunite` para preparação de impressão.
- LibreOffice **26.8.3.1**: Writer, Calc, Impress, Draw e Math; DOC/DOCX/ODT, XLS/XLSX/ODS, PPT/PPTX/ODP, desenhos, fórmulas e demais formatos já aceitos pelo explorador.
- WeasyPrint **70.0** com suas dependências Python: HTML/CSS estático, Markdown e preparação de imagens/texto para impressão. O renderizador mantém compatibilidade com a API anterior usada pela instalação nativa.
- MIT Kerberos **1.22.2**: biblioteca exigida pelo motor LibreOffice, sem ferramentas administrativas no pacote.

Os limites, cancelamento, cópias temporárias, perfil Office separado e bloqueio de macros/conteúdo ativo continuam aplicados. HTML não executa JavaScript nem busca recursos remotos. A paginação pode variar conforme as fontes. Documentos inválidos, protegidos ou não suportados continuam usando os avisos e ícones de fallback.

`FLATPAK-DBUS6-BUILD-INFO.json` registra o commit exato do explorador, hashes, SDK/runtime, versões e permissões; o código dessa revisão está no anexo **FLATPAK-DBUS6-APP-SOURCE.tar.gz**. Os botões automáticos “Source code” da release continuam apontando para a tag original dos pacotes nativos, portanto use o anexo específico para reconstruir este Flatpak.

**FLATPAK-PREVIEW-SOURCES.tar** contém os fontes correspondentes dos conversores, seus insumos fixados, locks, licenças e procedimento de build. É um download separado e não precisa ser instalado para usar o aplicativo. Quem redistribuir este bundle deve disponibilizar também esse arquivo no mesmo local. As licenças e avisos de terceiros acompanham a instalação; os componentes não são relicenciados como MIT.

## Testes e limitações

Passaram instalação nova, atualização da alpha.4 `flatpak-previews-dbus` anterior na mesma origem/ref, preservação exata das preferências, abertura gráfica, reutilização de janelas e remoção em containers descartáveis com Flatpak 1.14.6, **proxies 0.1.5 e 0.1.9**, D-Bus próprio e Xvfb/software OpenGL. **44 testes funcionais no sandbox em cada versão do proxy** cobrem operações, teclado/painéis, PDF, famílias Office, HTML/Markdown, miniaturas e preparação de impressão, verificando conteúdo e preservação dos originais. Nenhum documento foi enviado a uma impressora. Consulte `FLATPAK-DBUS6-VALIDATION.json` para o resultado do pacote exato.

Também passaram os testes de transporte com proxy real filtrado para OpenFile/Abrir com e Print: passagem de descritores, confirmação, cancelamento e erros, usando portais simulados em barramento privado. Os testes não chamam o portal da sessão do usuário nem enviam documentos a uma impressora. Os 363 testes Rust, 35 testes Python e Clippy completaram a validação do código.

A sessão real KDE/GNOME/Wayland e a impressão física permanecem sem certificação. Aplicativos do menu do host, novas conexões remotas, gerenciamento Samba local, unidades UDisks2 e FileManager1 continuam pendentes no Flatpak; pastas remotas já montadas dependem dos caminhos expostos. O terminal executa no sandbox, e a Lixeira usa dados XDG próprios. As permissões continuam sem rede própria, execução no host ou acesso irrestrito ao D-Bus.

`FLATPAK-DBUS6-RUSTSEC-AUDIT.json` registra a auditoria sem vulnerabilidades conhecidas. Os componentes aposentados `zbus_names`, `zvariant` e `zvariant_derive` saíram do lock, eliminando os três avisos D-Bus sem suprimir a auditoria. Resta o aviso independente de manutenção de `ttf-parser`. O relatório não representa auditoria de segurança dos motores nativos incluídos.

O crate oficial zbus 6.2.1 está incorporado com sua licença MIT e um patch local restrito a `connection/handshake/client.rs`. A origem, o commit upstream, os hashes por arquivo e o diff acompanham o código em `vendor/zbus`, `packaging/third-party/zbus-source.json` e `packaging/patches/zbus-flatpak-auth.patch`. O arquivo `FLATPAK-DBUS6-APP-SOURCE.tar.gz` contém esses fontes completos. O pacote também inclui o fonte modificado, a licença, a proveniência e o patch junto dos avisos de terceiros. CI e empacotamento verificam a integridade. Esse backport exige acompanhamento das atualizações upstream; não é uma alegação de suporte ao proxy antigo pelo zbus 6 original.

O ajuste mantém validação de autenticação, GUID e capacidade de descritores; não relaxa a filtragem nem as permissões. Testes com pares simulados também verificam rejeição de autenticação, GUID inválido/diferente e recusa segura de descritores, inclusive no Flatpak instalado. Relate problemas em https://github.com/janderpt/linux-system-explorer/issues, sem senhas ou documentos privados.

## English summary

This experimental x86_64 variant bundles Poppler, LibreOffice and WeasyPrint for PDF/Office/static HTML/Markdown previews, thumbnails and print preparation; host converter installations are unnecessary. It requires distribution-maintained Flatpak/D-Bus packages and Freedesktop Platform 26.08. A narrowly scoped, verified authentication backport on zbus 6.2.1 supports distribution proxy 0.1.5; both 0.1.5 and 0.1.9 were tested, without manually replacing the host proxy. Install with `flatpak install --user FILE.flatpak` and run `flatpak run --branch=experimental io.github.janderpt.linux-system-explorer`.

Upgrade the old alpha.4/alpha.2 experimental branch by installing this bundle without uninstalling or deleting data. The version string remains alpha.4, while the OSTree commit changes; origin/ref and private preferences are preserved. Fresh install, direct upgrade from the earlier zbus 5.19 alpha.4 Flatpak, Xvfb startup/removal, window reuse and **44 sandbox functional tests per proxy version** passed. Separate filtered-proxy mock-portal tests verify file-descriptor transport and opening/printing cancellation/errors. Real desktop/Wayland and physical-print validation remain separate. Existing host-integration limitations still apply.

The original native assets, tag and all earlier Flatpak variants remain available unchanged. Use **FLATPAK-DBUS6-APP-SOURCE.tar.gz** for the exact new explorer source and **FLATPAK-PREVIEW-SOURCES.tar** for the corresponding converter sources/build inputs. Redistributors must provide the converter source archive alongside this bundle. These source downloads are not needed to run the app. The prefixed build/validation/audit reports identify exact provenance, actual capabilities and test scope. RustSec reports no known vulnerable locked crates and none of the three retired D-Bus crate advisories; only the unrelated ttf-parser notice remains. The complete upstream zbus source, MIT license, local patch and provenance are included in the application-source archive and installed notices. The patch requires tracking upstream updates. Authentication/GUID validation, negotiated FD support and sandbox filtering remain enforced. This is not a Flathub submission or a stable/store-certified release.
