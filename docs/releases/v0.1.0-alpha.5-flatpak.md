# Linux System Explorer alpha.5 — Flatpak experimental

Publicado em **13/11/2026 (UTC)**, com o novo botão **Sobre** (ⓘ) ao lado da engrenagem: ícone oficial, autoria, versão, data, licença e links do projeto, em português e inglês. Fecha com Esc ou Fechar.

## Downloads e checksums

Em https://github.com/janderpt/linux-system-explorer/releases/tag/v0.1.0-alpha.5, baixe:

- **linux-system-explorer-0.1.0-alpha.5-flatpak-previews-x86_64.flatpak** — aplicativo x86_64 com previews.
- **FLATPAK-SHA256SUMS** — checksums deste Flatpak e seus anexos.
- **FLATPAK-BUILD-INFO.json**, **FLATPAK-VALIDATION.json** e **FLATPAK-RUSTSEC-AUDIT.json** — origem, capacidades e verificações.
- **FLATPAK-APP-SOURCE.tar.gz** — fontes exatos do explorador, incluindo zbus modificado, licença, patch e proveniência.
- **FLATPAK-PREVIEW-SOURCES.tar** — fontes correspondentes dos conversores, insumos, locks e licenças. É separado e não precisa ser instalado para usar o app.

Para verificar somente o bundle:

```sh
grep '  linux-system-explorer-0.1.0-alpha.5-flatpak-previews-x86_64.flatpak$' FLATPAK-SHA256SUMS | sha256sum --check -
```

Se baixou todos os anexos listados, use `sha256sum --check FLATPAK-SHA256SUMS`. O arquivo `SHA256SUMS` desta release atende exclusivamente os pacotes nativos.

## Instalação e execução

Requer Flatpak mantido pela distribuição e Freedesktop Platform **26.08**. O runtime vem do Flathub; o aplicativo vem deste arquivo local. Na pasta do download:

```sh
flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user ./linux-system-explorer-0.1.0-alpha.5-flatpak-previews-x86_64.flatpak
flatpak run --branch=experimental io.github.janderpt.linux-system-explorer
```

É um bundle experimental sem assinatura GPG, repositório próprio de atualização automática ou publicação no Flathub. Não substitui o explorador padrão automaticamente.

## Atualizar da alpha.4

Feche suas janelas Flatpak. Instale o novo arquivo com o mesmo comando, **sem desinstalar a versão anterior e sem apagar os dados**:

```sh
flatpak install --user ./linux-system-explorer-0.1.0-alpha.5-flatpak-previews-x86_64.flatpak
flatpak info --user io.github.janderpt.linux-system-explorer//experimental
flatpak run --branch=experimental io.github.janderpt.linux-system-explorer
```

O ID, a origem, a branch `experimental` e as preferências em `~/.var/app/io.github.janderpt.linux-system-explorer/` permanecem. Não use `--delete-data`. Esta publicação testa diretamente a atualização do último **alpha.4 flatpak-previews-dbus6**. As variantes alpha.4 e seus checksums permanecem inalterados; as atualizações anteriores já verificaram os demais saltos de versão.

Para remover mantendo seus dados:

```sh
flatpak uninstall --user io.github.janderpt.linux-system-explorer//experimental
```

## Previews e D-Bus incluídos

- **Poppler 26.11.0 / poppler-data 0.4.12:** PDF, páginas, miniaturas e preparação de impressão.
- **LibreOffice 26.8.3.1:** DOC/DOCX/ODT, XLS/XLSX/ODS, PPT/PPTX/ODP e demais famílias Office/OpenDocument já aceitas pelo explorador.
- **WeasyPrint 70.0:** apresentação estática de HTML/Markdown e preparação de imagens/texto para impressão, com dependências Python fixadas.
- **MIT Kerberos 1.22.2:** biblioteca necessária ao conversor Office, sem ferramentas administrativas.
- **zbus 6.2.1:** fonte oficial com backport local de autenticação sequencial no Flatpak, compatível com os proxies **0.1.5 e 0.1.9**, mantendo validação de autenticação, GUID e negociação de descritores. Não exige atualização manual do xdg-dbus-proxy.

Os conversores não dependem dos programas instalados no host. HTML não executa JavaScript nem busca recursos remotos; conversões Office usam perfil privado e desativam macros/conteúdo ativo. Os limites, cancelamento, fontes disponíveis, codecs e documentos inválidos/protegidos continuam afetando o preview. O app informa falhas pelos toasts.

O fonte completo do zbus, licença MIT original, patch e hashes estão em `vendor/zbus`, `packaging/patches/zbus-flatpak-auth.patch` e `packaging/third-party/zbus-source.json`, incluídos no anexo de fontes do explorador e nos avisos do pacote. A integridade é verificada por CI/empacotamento. O patch precisa acompanhar futuras atualizações upstream; não constitui promessa de suporte ao proxy antigo pelo upstream original.

Quem redistribuir o bundle deve disponibilizar também os fontes correspondentes **FLATPAK-APP-SOURCE.tar.gz** e **FLATPAK-PREVIEW-SOURCES.tar** no mesmo local. Os componentes preservam suas licenças próprias. O tag da alpha.5 e os fontes anexados identificam a mesma revisão usada nos pacotes nativos e Flatpak.

## Validação e limitações

O relatório **FLATPAK-VALIDATION.json** registra o pacote exato: proxies **0.1.5 e 0.1.9**, instalação nova, atualização da alpha.4 na mesma origem/ref, preservação das preferências, inicialização Xvfb/software OpenGL, reutilização de janelas, operações e conversores no sandbox e remoção. Testes separados com portais simulados/barramento privado verificam passagem de descritores, confirmação/cancelamento e erros de abertura/impressão. Nenhum documento é enviado a uma impressora nesses testes.

A conferência do botão Sobre inclui os temas claro/escuro, Esc e teste local confirmado pelo usuário no KDE. Impressão física e a matriz completa KDE/GNOME/X11/Wayland ainda não foram certificadas. Este pacote não tem integração completa com aplicativos do host, novas conexões remotas, Samba local, unidades UDisks2 ou registro FileManager1; pastas remotas já montadas dependem dos caminhos expostos. Terminal e Lixeira usam o ambiente do sandbox. As permissões não incluem execução no host, rede própria ou D-Bus irrestrito.

A auditoria Rust sem supressões não encontrou vulnerabilidades conhecidas e não contém os três avisos dos componentes D-Bus aposentados. Permanece o aviso independente de manutenção de `ttf-parser` (RUSTSEC-2026-0192). A auditoria Rust não representa auditoria dos conversores. Consulte os relatórios e avisos incluídos. Relate problemas em https://github.com/janderpt/linux-system-explorer/issues sem senhas ou documentos privados.

## English summary

Alpha.5 adds the **About** toolbar button with the official icon, author, version, publication date (**2026-11-13 UTC**), MIT license and project links. It supports Portuguese/English and Escape dismissal.

Download the **flatpak-previews** bundle and verify **FLATPAK-SHA256SUMS**. Add the Flathub runtime remote, then use `flatpak install --user ./linux-system-explorer-0.1.0-alpha.5-flatpak-previews-x86_64.flatpak` and `flatpak run --branch=experimental io.github.janderpt.linux-system-explorer`. Upgrade alpha.4 on the same branch without uninstalling or deleting data. Origin/ref and private preferences are retained; no automatic app repository update is configured.

Poppler, LibreOffice and WeasyPrint provide PDF/Office/static HTML/Markdown previews inside the sandbox. The verified zbus 6.2.1 authentication backport supports distribution proxies **0.1.5 and 0.1.9**, without manually replacing them. **FLATPAK-APP-SOURCE.tar.gz** contains exact application/modified zbus sources, license, patch and provenance; **FLATPAK-PREVIEW-SOURCES.tar** contains corresponding converter sources/build inputs. Both must accompany redistribution, but need not be installed to run the app. Tag, native packages and Flatpak identify the same application-source commit. Prior releases remain untouched.

Build/validation/audit reports describe exact scope and remaining host-integration limitations. Full desktop/Wayland and physical printing validation remain separate. The unrelated `ttf-parser` maintenance notice is documented. This experimental bundle is not a stable or Flathub-certified release.
