# Linux System Explorer v0.1.0-alpha.1

Primeira pré-release para testes, Linux **x86_64/amd64**, compilada no **Ubuntu 24.04 (glibc 2.39)**. Não é uma versão estável nem um AppImage/Flatpak. Outras distribuições precisam de ABI e dependências compatíveis; sistemas com glibc anterior a 2.39 não são suportados por estes binários.

## Novidades

- Abas, histórico de abas fechadas, terminal integrado e dois painéis independentes, com restauração da sessão e proporção.
- Preferências por pasta, seleção múltipla, copiar/recortar/colar, arrastar e soltar, renomear e Lixeira.
- Conexões de rede, navegação SMB e gerenciamento de compartilhamentos locais Samba.
- Preview com Espaço para imagens, áudio/vídeo, PDF, Microsoft Office/OpenDocument, HTML/Markdown e conteúdo de compactados.
- ↑/↓ alternam arquivos; ←/→ alternam páginas/slides; Espaço/Esc fecha o preview. Rodapé fixo e controles centralizados.
- Interface em português/inglês e ícones configuráveis.

## Downloads e integridade

Baixe o `.deb` ou `.tar.gz`, `BUILD-INFO.json` e `SHA256SUMS` desta release. Para verificar tudo, baixe ambos os pacotes e execute na pasta dos downloads:

```sh
sha256sum --check SHA256SUMS
```

Se baixou apenas um pacote, verifique sua linha (e repita para BUILD-INFO.json, se desejado):

```sh
grep '  linux-system-explorer_0.1.0~alpha.1-1_amd64.deb$' SHA256SUMS | sha256sum --check -
# ou
grep '  linux-system-explorer-0.1.0-alpha.1-x86_64-unknown-linux-gnu.tar.gz$' SHA256SUMS | sha256sum --check -
```

## Instalar o DEB — Ubuntu 24.04+

```sh
sudo apt update
sudo apt install ./linux-system-explorer_0.1.0~alpha.1-1_amd64.deb
linux-system-explorer
```

O APT instala as dependências declaradas, incluindo os componentes de preview. Use a sessão gráfica do seu usuário, sem executar o explorador como root. A instalação do DEB não muda automaticamente o gerenciador de arquivos padrão. Para remover:

```sh
sudo apt remove linux-system-explorer
```

As preferências do usuário permanecem nos diretórios XDG. Ao atualizar/reinstalar, feche e reabra todas as janelas. Uma instalação anterior em `~/.local/bin` tem prioridade sobre `/usr/bin`; confira `command -v linux-system-explorer` e use `/usr/bin/linux-system-explorer` para testar este DEB.

## Executar o TAR.GZ

Este arquivo contém um executável nativo e os metadados/licenças; não inclui as bibliotecas do sistema. No Ubuntu 24.04+, instale os runtimes:

```sh
sudo apt install libx11-6 libxi6 libxcursor1 libxrandr2 libxkbcommon0 libxkbcommon-x11-0 libwayland-client0 libegl1 libgl1 libglib2.0-bin xdg-utils shared-mime-info hicolor-icon-theme poppler-utils libgstreamer1.0-0 libgstreamer-plugins-base1.0-0 gstreamer1.0-plugins-base gstreamer1.0-plugins-good gstreamer1.0-libav libreoffice-writer libreoffice-calc libreoffice-impress libreoffice-draw libreoffice-math fonts-liberation weasyprint python3 libarchive13t64

tar -xzf linux-system-explorer-0.1.0-alpha.1-x86_64-unknown-linux-gnu.tar.gz
./linux-system-explorer-0.1.0-alpha.1/bin/linux-system-explorer
```

Também é possível informar uma pasta após o executável. Os avisos de terceiros, fontes MPL e instruções ficam em `share/licenses` e `share/doc`.

## Tornar padrão / Mostrar na pasta

A integração é opcional. Siga o [instalador por usuário e sua restauração](https://github.com/janderpt/linux-system-explorer/tree/v0.1.0-alpha.1#instalar-pelo-código-do-github), usando o código da tag `v0.1.0-alpha.1`. Ele preserva os registros anteriores e configura `inode/directory` e FileManager1. Não habilite duas instalações diferentes para o mesmo usuário.

## Limitações e validação

- Pacotes para Ubuntu 24.04 x86_64, com checksums, metadados de origem, testes automáticos e testes de instalação/reinstalação/remoção em container limpo. A interface foi testada em KDE durante o desenvolvimento; a matriz completa GNOME/KDE e Wayland/X11 ainda não foi certificada.
- Clipboard de arquivos entre outros gerenciadores e este app ainda não implementa os formatos MIME nativos; arrastar e soltar é uma integração separada.
- Rede depende dos módulos GVfs/GTK ou KIO do desktop. O servidor Samba é opcional e não é instalado/configurado automaticamente.
- Office usa conversão estática pelo LibreOffice; HTML/Markdown usam apresentação estática, sem JavaScript. Arquivos protegidos/danificados, codecs ausentes ou limites de recursos podem impedir previews.
- RustSec reporta `ttf-parser` como não mantido (RUSTSEC-2026-0192); é uma dependência indireta do renderizador. O relatório de auditoria está anexado. As licenças, avisos e fontes MPL acompanham cada pacote; a revisão técnica está em `DISTRIBUTION-REVIEW.md`.

Relate problemas em https://github.com/janderpt/linux-system-explorer/issues, incluindo versão, distribuição, desktop, X11/Wayland e passos para reproduzir, sem senhas ou arquivos privados.

## English installation summary

First **alpha**, **Ubuntu 24.04+ x86_64**, built against glibc 2.39. Verify the downloaded assets with SHA256SUMS. Install the DEB using `sudo apt install ./linux-system-explorer_0.1.0~alpha.1-1_amd64.deb`; uninstall with `sudo apt remove linux-system-explorer`. Or install the listed runtimes, extract the TAR.GZ and run `linux-system-explorer-0.1.0-alpha.1/bin/linux-system-explorer` in your graphical user session. Neither package changes the default file manager automatically. Close/reopen windows after updates and check for an older `~/.local/bin` installation shadowing `/usr/bin`.

The alpha includes tabs, split panes, per-folder layouts, an integrated terminal, network shares, Trash/file operations and internal previews. Native clipboard MIME interoperability, the complete desktop/session matrix and store/sandbox integration remain pending. The attached audit records the unmaintained `ttf-parser` transitive dependency. Each package includes third-party notices and the unmodified MPL-covered crate sources. Please use disposable files during testing and report reproducible issues without private data.
