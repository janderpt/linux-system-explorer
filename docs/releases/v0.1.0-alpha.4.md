# Linux System Explorer v0.1.0-alpha.4

Quarta pré-release para testes. Os pacotes nativos `.deb` e `.tar.gz` são para Linux **x86_64/amd64**, compilados no **Ubuntu 24.04 (glibc 2.39)**. A seção Flatpak descreve um bundle experimental separado. Esta não é uma versão estável nem um AppImage. Outras distribuições precisam de ABI e dependências compatíveis; sistemas com glibc anterior a 2.39 não são suportados por estes binários.

## Flatpak experimental — instalação e atualização

Além dos pacotes nativos, esta release inclui `linux-system-explorer-0.1.0-alpha.4-flatpak-experimental-x86_64.flatpak`. **É experimental, não é uma publicação no Flathub e tem limitações de recursos.** Requer Flatpak atualizado, `xdg-dbus-proxy` 0.1.9+ no host e Freedesktop Platform 26.08.

Baixe também [INSTALL-FLATPAK.md](https://github.com/janderpt/linux-system-explorer/releases/download/v0.1.0-alpha.4/INSTALL-FLATPAK.md), [FLATPAK-SHA256SUMS](https://github.com/janderpt/linux-system-explorer/releases/download/v0.1.0-alpha.4/FLATPAK-SHA256SUMS), `FLATPAK-BUILD-INFO.json` e `FLATPAK-VALIDATION.json`. O manifesto `SHA256SUMS` dos pacotes nativos permanece inalterado.

```sh
sha256sum --check FLATPAK-SHA256SUMS
flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user ./linux-system-explorer-0.1.0-alpha.4-flatpak-experimental-x86_64.flatpak
flatpak run --branch=experimental io.github.janderpt.linux-system-explorer
```

Para atualizar a alpha.2 experimental, feche suas janelas e repita a instalação do novo bundle **sem desinstalar nem usar `--delete-data`**. A origem, a branch e as preferências privadas são preservadas; a instalação nativa e o gerenciador padrão não são alterados. O runtime é baixado separadamente; o bundle não tem assinatura GPG ou atualizações automáticas por repositório próprio.

Passaram instalação nova, atualização alpha.2 → alpha.4, preservação das preferências, abertura Xvfb e remoção, além de **33 testes funcionais no sandbox**, em ambiente isolado. A sessão real KDE/GNOME e Wayland permanece sem certificação. **Poppler, LibreOffice e WeasyPrint não estão incluídos**: previews PDF/Office e apresentação HTML/Markdown, além de várias integrações do host, continuam pendentes. Consulte as instruções anexadas para os detalhes.

## Correções e melhorias desde a alpha.3

- **FTP:** autenticação gráfica por GVfs também no KDE quando disponível; uploads deixam de falhar por atributos Unix não suportados. Gravação, fechamento do arquivo e conflitos continuam sendo verificados.
- **Preview de PDF pelo FTP:** cópia temporária privada para montagens com leitura sequencial, reutilizada entre páginas e removida ao encerrar. A mesma preparação atende miniaturas e impressão; o arquivo remoto permanece intacto. A opção do menu indica **Pré-visualizar (space)**.
- **Excluir no FTP:** Del e Shift+Del pedem confirmação para exclusão permanente no servidor, sem oferecer Lixeira indisponível.
- **Arrastar e soltar:** card junto ao cursor identifica o arquivo ou a quantidade. Ao soltar em uma pasta do explorador, escolha explicitamente **Copiar**, **Mover** ou **Cancelar**; Ctrl/Shift sugerem a operação. Arrastes com outros aplicativos respeitam as ações negociadas com a origem.
- **Teclado:** digitar o início de um nome seleciona e revela o item; Enter abre a pasta ou o arquivo no aplicativo padrão. No campo de busca, ↑ entra pelo último resultado e ↓ pelo primeiro; as setas continuam navegando sem limpar a pesquisa recursiva.
- **Barra lateral:** ao entrar em uma pasta, rola até o ancestral destacado mais próximo, incluindo compartilhamentos, pastas fixadas e unidades. Painéis e abas mantêm rolagem independente, preservando a rolagem manual posterior.
- **Toasts:** mensagens crescem conforme o conteúdo até a altura disponível na janela, com rolagem apenas quando a pilha ultrapassa esse espaço.

Continuam disponíveis os recursos da alpha.3: busca recursiva e abertura do local do resultado, unidades, personalização por pasta, aplicativos, ações de imagens/compactados, impressão, miniaturas, abas, dois painéis e terminal integrado. Os READMEs em português e inglês detalham o comportamento.

O nome público do DEB usa `.alpha.4`; a versão interna é `0.1.0~alpha.4-1`, para ordenar corretamente antes da versão final. Feche e reabra todas as janelas depois de atualizar.

## Downloads e integridade

Baixe o `.deb` ou `.tar.gz`, `BUILD-INFO.json` e `SHA256SUMS` desta release. Para verificar tudo, baixe todos os anexos listados em `SHA256SUMS` (os dois pacotes, metadados, relatórios e instruções) e execute na pasta dos downloads:

```sh
sha256sum --check SHA256SUMS
```

Se baixou apenas um pacote, verifique sua linha (e repita para BUILD-INFO.json, se desejado):

```sh
grep '  linux-system-explorer_0.1.0.alpha.4-1_amd64.deb$' SHA256SUMS | sha256sum --check -
# ou
grep '  linux-system-explorer-0.1.0-alpha.4-x86_64-unknown-linux-gnu.tar.gz$' SHA256SUMS | sha256sum --check -
```

## Instalar o DEB — Ubuntu 24.04+

```sh
sudo apt update
sudo apt install ./linux-system-explorer_0.1.0.alpha.4-1_amd64.deb
linux-system-explorer
```

O APT instala as dependências declaradas, incluindo os componentes de preview. Use a sessão gráfica do seu usuário, sem executar o explorador como root. A instalação do DEB não muda automaticamente o gerenciador de arquivos padrão. Para remover:

```sh
sudo apt remove linux-system-explorer
```

Para atualizar a alpha.1, alpha.2 ou alpha.3 instalada por DEB, use o mesmo comando de instalação acima; o APT reconhece a alpha.4 como mais recente. As preferências do usuário permanecem nos diretórios XDG. Ao atualizar/reinstalar, feche e reabra todas as janelas. Uma instalação anterior em `~/.local/bin` tem prioridade sobre `/usr/bin`; confira `command -v linux-system-explorer` e use `/usr/bin/linux-system-explorer` para testar este DEB.

## Executar o TAR.GZ

Este arquivo contém um executável nativo e os metadados/licenças; não inclui as bibliotecas do sistema. No Ubuntu 24.04+, instale os runtimes:

```sh
sudo apt install libx11-6 libxi6 libxcursor1 libxrandr2 libxkbcommon0 libxkbcommon-x11-0 libwayland-client0 libegl1 libgl1 libglib2.0-bin xdg-utils shared-mime-info hicolor-icon-theme poppler-utils libgstreamer1.0-0 libgstreamer-plugins-base1.0-0 gstreamer1.0-plugins-base gstreamer1.0-plugins-good gstreamer1.0-libav libreoffice-writer libreoffice-calc libreoffice-impress libreoffice-draw libreoffice-math fonts-liberation weasyprint python3 libarchive13t64 udisks2 polkitd xdg-desktop-portal

tar -xzf linux-system-explorer-0.1.0-alpha.4-x86_64-unknown-linux-gnu.tar.gz
./linux-system-explorer-0.1.0-alpha.4/bin/linux-system-explorer
```

Para atualizar uma instalação TAR.GZ, extraia a alpha.4 em uma nova pasta e passe a usar o novo executável; ajuste seu atalho se ele apontava para uma pasta de versão anterior. As preferências do usuário são preservadas. Feche as janelas antigas antes de testar.

Também é possível informar uma pasta após o executável. Os avisos de terceiros, fontes MPL e instruções ficam em `share/licenses` e `share/doc`.

## FTP e outros acessos remotos

Para autenticação e montagem FTP por GVfs, inclusive no KDE, instale no Ubuntu 24.04+:

```sh
sudo apt install gvfs-backends gvfs-fuse libgtk-3-0t64
```

Use **Rede → Adicionar compartilhamento de rede** ou Ctrl+L e informe `ftp://usuario@servidor/pasta/`. Digite a senha somente na janela gráfica do sistema. No KDE, KIO Fuse continua disponível para os protocolos atendidos por `kio-fuse` e `kio-extras`. Não é necessário instalar um servidor Samba para acessar um FTP externo.

## Tornar padrão / Mostrar na pasta

A integração é opcional. Siga o [instalador por usuário e sua restauração](https://github.com/janderpt/linux-system-explorer/tree/v0.1.0-alpha.4#instalar-pelo-código-do-github), usando o código da tag `v0.1.0-alpha.4`. Ele preserva os registros anteriores e configura `inode/directory` e FileManager1. Não habilite duas instalações diferentes para o mesmo usuário.

## Limitações e validação

- O workflow exige testes automáticos, auditoria, validação de origem/licenças e instalação/reinstalação/remoção em Ubuntu 24.04 limpo antes de publicar. A interface foi testada em KDE durante o desenvolvimento, incluindo testes confirmados pelo usuário de autenticação, upload e preview PDF em FTP, atalhos, dois painéis e rolagem da barra lateral. Testes de transferências e exclusões remotas usam um FTP local descartável; a verificação do PDF remoto foi somente de leitura. Montagem/desmontagem/ejeção foram verificadas em um serviço simulado, com inventário real lido sem alterações. O diálogo de impressão foi conferido com cancelamento; a impressão física e a matriz completa GNOME/KDE e Wayland/X11 ainda não foram certificadas.
- Clipboard de arquivos entre outros gerenciadores e este app ainda não implementa os formatos MIME nativos; arrastar e soltar é uma integração separada.
- Unidades criptografadas precisam estar desbloqueadas; o desbloqueio não faz parte desta versão. Aplicativos, gerenciadores de software, extração e serviços de armazenamento dependem dos componentes fornecidos pelo desktop.
- Rede depende dos módulos GVfs/GTK ou KIO do desktop. O servidor Samba é opcional e não é instalado/configurado automaticamente.
- Office usa conversão estática pelo LibreOffice; HTML/Markdown usam apresentação estática, sem JavaScript. Arquivos protegidos/danificados, codecs ausentes ou limites de recursos podem impedir previews.
- RustSec reporta `ttf-parser` como não mantido (RUSTSEC-2026-0192); é uma dependência indireta do renderizador. O relatório de auditoria está anexado. As licenças, avisos e fontes MPL acompanham cada pacote; a revisão técnica está em `DISTRIBUTION-REVIEW.md`.

Relate problemas em https://github.com/janderpt/linux-system-explorer/issues, incluindo versão, distribuição, desktop, X11/Wayland e passos para reproduzir, sem senhas ou arquivos privados.

## English installation summary

Fourth **alpha**, **Ubuntu 24.04+ x86_64**, built against glibc 2.39. Verify downloads using SHA256SUMS. Install or upgrade with `sudo apt install ./linux-system-explorer_0.1.0.alpha.4-1_amd64.deb`; remove with `sudo apt remove linux-system-explorer`. Or install the listed native runtimes, extract the TAR.GZ and run `linux-system-explorer-0.1.0-alpha.4/bin/linux-system-explorer` in your graphical user session. Neither package changes the default file manager automatically. Close/reopen all windows after updating; check for an older `~/.local/bin` installation shadowing `/usr/bin`.

New since alpha.3: native FTP authentication and upload fixes, reusable temporary PDF snapshots for sequential remote streams, confirmed permanent FTP deletion, drag cards and explicit Copy/Move/Cancel drop choices, name-prefix selection and Enter opening, filter-to-results arrow navigation, independent sidebar ancestor reveal and window-bounded toast sizing. Existing features remain available. For FTP authentication/mounting on Ubuntu 24.04+, install `gvfs-backends gvfs-fuse libgtk-3-0t64`, including on KDE; credentials stay in the system dialog.

To upgrade alpha.1/alpha.2/alpha.3 DEB installations, use the same APT command above; preferences are preserved. TAR.GZ users should extract alpha.4 to a new directory and point their launcher to its executable. Neither format changes the default file manager automatically. The separate experimental Flatpak is attached with INSTALL-FLATPAK.md, prefixed build/validation reports and FLATPAK-SHA256SUMS; it is not a Flathub or certified store package. See its instructions and capability limitations before installing.

The publication workflow checks tests/audit/notices and clean-container package installation/removal. KDE interface testing includes user-confirmed FTP authentication/upload/PDF preview and two-pane navigation; destructive remote tests use a disposable local FTP fixture, and the real remote PDF check is read only. Volume actions were tested on a simulated service with read-only real inventory; the native print dialog was tested by cancelling. Physical printing and the full desktop/session matrix remain unverified. The audit records the informational unmaintained `ttf-parser` dependency. Packages include third-party notices and unmodified MPL-covered crate sources. Report reproducible problems without private files or credentials.
