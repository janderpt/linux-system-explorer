# Linux System Explorer v0.1.0-alpha.5

Quinta pré-release para testes, publicada em **13/11/2026 (UTC)**. Inclui pacotes nativos **Ubuntu 24.04+ x86_64/amd64 (glibc 2.39)** e um **Flatpak experimental x86_64**, com fontes, relatórios e checksums separados. Ainda não é uma versão estável nem uma publicação no Flathub.

## Novidades

- **Sobre:** botão de informação (ⓘ) ao lado da engrenagem na toolbar. Mostra o ícone oficial em destaque, autoria de Jander Tavares, versão, data de publicação, licença MIT e links para fontes, downloads e problemas. Disponível em português e inglês; fecha com Esc ou Fechar. A data é explícita e compartilhada com o AppStream, sem mudar a cada recompilação.
- **D-Bus:** pacotes nativos e Flatpak usam **zbus 6.2.1**, com o backport de autenticação sequencial no Flatpak para **xdg-dbus-proxy 0.1.5 e 0.1.9**, mantendo validação de autenticação/GUID/descritores. Não exige substituir manualmente o proxy. Os componentes aposentados zvariant, zvariant_derive e zbus_names e seus avisos saíram do lock. O fonte modificado, licença MIT, patch, hashes e proveniência acompanham os fontes e os avisos do pacote.
- **Flatpak com previews:** inclui Poppler **26.11.0**, LibreOffice **26.8.3.1** e WeasyPrint **70.0**, para PDF, Office/OpenDocument, apresentação HTML/Markdown, miniaturas e preparação de impressão sem os conversores do host.

Permanecem disponíveis as funções da alpha.4: FTP, confirmação de exclusão remota, busca recursiva, navegação por teclado, arrastar com escolha Copiar/Mover, abas, dois painéis, terminal, miniaturas, propriedades/personalização por pasta, unidades e compartilhamentos. As integrações do host continuam mais completas no pacote nativo.

## Downloads e verificação

Baixe os arquivos desta release em https://github.com/janderpt/linux-system-explorer/releases/tag/v0.1.0-alpha.5.

- Nativo: `linux-system-explorer_0.1.0.alpha.5-1_amd64.deb` ou `linux-system-explorer-0.1.0-alpha.5-x86_64-unknown-linux-gnu.tar.gz`, com `SHA256SUMS` e `BUILD-INFO.json`.
- Flatpak: `linux-system-explorer-0.1.0-alpha.5-flatpak-previews-x86_64.flatpak`, com **FLATPAK-SHA256SUMS** e **INSTALL-FLATPAK.md**.
- Fontes do explorador: **FLATPAK-APP-SOURCE.tar.gz** e os botões Source code da tag, todos referentes ao mesmo commit da alpha.5.
- Fontes correspondentes dos conversores: **FLATPAK-PREVIEW-SOURCES.tar**, download separado necessário para redistribuição, não para executar o app.

Na pasta dos downloads, verifique a linha do formato escolhido:

```sh
grep '  linux-system-explorer_0.1.0.alpha.5-1_amd64.deb$' SHA256SUMS | sha256sum --check -
# ou
grep '  linux-system-explorer-0.1.0-alpha.5-x86_64-unknown-linux-gnu.tar.gz$' SHA256SUMS | sha256sum --check -
# ou, para Flatpak
grep '  linux-system-explorer-0.1.0-alpha.5-flatpak-previews-x86_64.flatpak$' FLATPAK-SHA256SUMS | sha256sum --check -
```

Se baixou todos os anexos listados em cada manifesto, execute `sha256sum --check SHA256SUMS` ou `sha256sum --check FLATPAK-SHA256SUMS`. Os manifestos são independentes; não use o checksum nativo para verificar o Flatpak.

## Instalar ou atualizar o DEB

Feche as janelas antigas, abra um terminal na pasta do download e execute:

```sh
sudo apt update
sudo apt install ./linux-system-explorer_0.1.0.alpha.5-1_amd64.deb
/usr/bin/linux-system-explorer
```

O mesmo comando atualiza uma alpha.4 ou outra alpha anterior, preservando as preferências XDG. A versão interna Debian é `0.1.0~alpha.5-1`; ela ordena antes da versão estável futura. O APT instala os runtimes declarados, incluindo os conversores de preview. O pacote não altera o explorador padrão automaticamente. Execute na sessão gráfica de seu usuário, sem root.

Uma instalação anterior em `~/.local/bin` pode ter prioridade: confira `command -v linux-system-explorer` e use `/usr/bin/linux-system-explorer` para testar o DEB. Para remover, use `sudo apt remove linux-system-explorer`.

## Executar ou atualizar o TAR.GZ

O TAR inclui executável, metadados, licenças e fontes de dependências exigidos pelos avisos; as bibliotecas e conversores nativos são fornecidos pela distribuição. No Ubuntu 24.04+:

```sh
sudo apt install libx11-6 libxi6 libxcursor1 libxrandr2 libxkbcommon0 libxkbcommon-x11-0 libwayland-client0 libegl1 libgl1 libglib2.0-bin xdg-utils shared-mime-info hicolor-icon-theme poppler-utils libgstreamer1.0-0 libgstreamer-plugins-base1.0-0 gstreamer1.0-plugins-base gstreamer1.0-plugins-good gstreamer1.0-libav libreoffice-writer libreoffice-calc libreoffice-impress libreoffice-draw libreoffice-math fonts-liberation weasyprint python3 libarchive13t64 udisks2 polkitd xdg-desktop-portal
tar -xzf linux-system-explorer-0.1.0-alpha.5-x86_64-unknown-linux-gnu.tar.gz
./linux-system-explorer-0.1.0-alpha.5/bin/linux-system-explorer
```

Para atualizar, extraia em uma nova pasta e aponte o atalho para o novo executável. Feche as janelas antigas; as preferências XDG permanecem. Outras distribuições exigem ABI e dependências compatíveis; os binários nativos não atendem glibc anterior a 2.39.

## Instalar ou atualizar o Flatpak

Use Flatpak mantido pela distribuição. O runtime é Freedesktop Platform **26.08**, obtido do Flathub; o aplicativo vem deste bundle do GitHub:

```sh
flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user ./linux-system-explorer-0.1.0-alpha.5-flatpak-previews-x86_64.flatpak
flatpak run --branch=experimental io.github.janderpt.linux-system-explorer
```

Para atualizar a alpha.4, feche as janelas Flatpak e instale o novo arquivo com o mesmo comando, **sem desinstalar nem apagar os dados**. ID, branch `experimental`, origem e preferências privadas são preservados. Não use `--delete-data`. Não há atualização automática por um repositório próprio. Para remover mantendo os dados:

```sh
flatpak uninstall --user io.github.janderpt.linux-system-explorer//experimental
```

Consulte [INSTALL-FLATPAK.md](https://github.com/janderpt/linux-system-explorer/releases/download/v0.1.0-alpha.5/INSTALL-FLATPAK.md) para fontes, testes e diferenças das integrações nativas.

## Integração nativa e limites

Para FTP com autenticação gráfica GVfs, inclusive no KDE, instale `gvfs-backends gvfs-fuse libgtk-3-0t64`. Para KIO, use `kio-fuse` e `kio-extras`. Informe senhas somente na janela do sistema. O servidor Samba é opcional e não é necessário para acessar FTP externo.

A configuração opcional de explorador padrão e Mostrar na pasta usa o [instalador por usuário](https://github.com/janderpt/linux-system-explorer/tree/v0.1.0-alpha.5#instalar-pelo-código-do-github) da tag `v0.1.0-alpha.5`, com backup/restauração. Não habilite duas instalações para o mesmo usuário.

O Flatpak ainda não oferece descoberta de aplicativos do host, novas conexões remotas, gerenciamento Samba local, unidades UDisks2 ou registro FileManager1. Usa permissões de arquivos e portais, sem execução no host nem D-Bus irrestrito. O terminal executa no sandbox. Conteúdo Office/HTML é estático; macros/JavaScript e recursos remotos não são executados. Codecs, fontes, documentos protegidos/danificados e limites de recursos podem impedir previews.

A validação inclui testes Rust/Python, Clippy, metadados, auditoria, instalação/reinstalação/remoção e abertura X11 em Ubuntu limpo. O botão Sobre foi conferido nos temas claro/escuro e confirmado pelo usuário no KDE. O Flatpak é testado com cada proxy, instalação nova e atualização da alpha.4 na mesma origem/ref, preservação de preferências, conversores e operações no sandbox. Os relatórios identificam o commit e o escopo exatos. A impressão física e a matriz completa KDE/GNOME/X11/Wayland ainda não foram certificadas.

RustSec não encontrou vulnerabilidades conhecidas no lock; permanece o aviso informativo de manutenção de `ttf-parser` (RUSTSEC-2026-0192). A auditoria Rust não é auditoria dos conversores nativos. Veja **RUSTSEC-AUDIT.json**, **FLATPAK-RUSTSEC-AUDIT.json**, os inventários de terceiros e **DISTRIBUTION-REVIEW.md**. O backport zbus exige acompanhamento upstream. As releases anteriores permanecem disponíveis sem alterações.

Relate problemas em https://github.com/janderpt/linux-system-explorer/issues com versão, distribuição, desktop e passos, sem senhas ou arquivos privados.

## English summary

Alpha.5 adds the **About** information button next to Settings, with the official icon, author, package version, publication date, MIT license and project links. It supports Portuguese/English, both themes and Escape dismissal. Publication date is **2026-11-13 UTC** and is shared with AppStream rather than inferred from build time.

Native **Ubuntu 24.04+ x86_64**: verify `SHA256SUMS`, then install/upgrade with `sudo apt install ./linux-system-explorer_0.1.0.alpha.5-1_amd64.deb`. Or extract `linux-system-explorer-0.1.0-alpha.5-x86_64-unknown-linux-gnu.tar.gz` after installing the listed runtimes. Preferences are retained; close old windows and check for an older `~/.local/bin` shadowing `/usr/bin`. Neither format changes the default file manager automatically.

Experimental **Flatpak**: verify **FLATPAK-SHA256SUMS**, add the Flathub runtime remote, install `linux-system-explorer-0.1.0-alpha.5-flatpak-previews-x86_64.flatpak` with `flatpak install --user ./FILE.flatpak`, then run `flatpak run --branch=experimental io.github.janderpt.linux-system-explorer`. Upgrade alpha.4 by installing this bundle without uninstalling or deleting data; origin/ref and private preferences are preserved. Poppler, LibreOffice and WeasyPrint are bundled. zbus 6.2.1 includes a verified authentication backport for proxies **0.1.5 and 0.1.9** without manual proxy replacement. Native and Flatpak packages share this tag's exact source. Download **FLATPAK-APP-SOURCE.tar.gz** and **FLATPAK-PREVIEW-SOURCES.tar** for corresponding application/converter sources; redistributors must provide them alongside the bundle. See **INSTALL-FLATPAK.md** for full instructions and host-integration limitations. No stable release, Flathub submission or full desktop certification is claimed; the independent `ttf-parser` maintenance notice remains documented.
