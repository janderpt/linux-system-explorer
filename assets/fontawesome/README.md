# Font Awesome Free 7.1.0

Fonte `fa-solid-900.otf` (original `otfs/Font Awesome 7 Free-Solid-900.otf`) e metadados obtidos da versão oficial:

https://github.com/FortAwesome/Font-Awesome/tree/7.1.0

`catalog.json` contém apenas os nomes, rótulos e códigos Unicode dos ícones com o estilo `solid` na lista `free` de `metadata/icons.json`. A fonte é incorporada ao executável; não há dependência de CDN ou acesso à rede em execução.
